# ⚪ 글로벌 축구 뉴스 플랫폼 (FIPA NEWS)

## 1. 프로젝트 개요 및 디자인 컨셉
- **목표**: 여러 구단의 소식을 한곳에서 볼 수 있는 멀티 클럽 뉴스 플랫폼.
- **디자인 테마**:
    - 각 구단 고유의 상징색(Primary/Secondary/Accent)을 동적으로 적용.
    - 랜딩 페이지에서 원하는 구단 플랫폼으로 진입 가능.
- **핵심 가치**: 멀티 테넌시(Multi-tenancy) 아키텍처, 구단별 맞춤형 UI, 실시간 데이터 시각화.

## 2. 기술 스택 (Tech Stack)
- **프레임워크**: Next.js (App Router 기반)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS v4 + CSS Variables injection
- **데이터 페칭**: OpenAPI SDK (SDK 기반의 타입 안정성)

## 3. 주요 기능 및 요구사항
### 3.1 멀티 클럽 지원
- **동적 라우팅**: `/[club]` 경로를 통해 각 구단별 독립적인 뉴스 피드 제공.
- **브랜딩 엔진**: `src/config/clubs.ts` 설정을 기반으로 헤더, 푸터, 히어로 섹션, 뉴스 카드 등의 테마를 실시간 변경.
- **구단 스위처**: 헤더 내 팀 변경 기능을 통해 다른 구단 플랫폼으로 즉시 이동 가능.

### 3.2 뉴스 대시보드
- **AI 요약**: 복잡한 외신 기사를 AI가 3줄 요약하여 가독성 증대.
- **반응형 디자인**: 모바일 최적화된 카드 UI 및 필터 시스템.

---

## 🚀 개발 및 확장 가이드
1. 새로운 구단을 추가하려면 `src/config/clubs.ts`에 구단 정보를 추가하면 됩니다.
2. 각 구단별 API 연동 시 필요한 파라미터는 백엔드 명세에 맞춰 확장 가능합니다.
3. 디자인 변경 시 `globals.css`의 CSS 변수 명칭(`--primary`, `--secondary` 등)을 활용하여 전역 테마를 관리합니다.
